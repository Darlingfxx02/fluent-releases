# Fluent

[Скачать последнюю версию](https://github.com/Darlingfxx02/fluent-releases/releases/latest)

- **macOS 13+ / Apple Silicon** — файл `.dmg`.
- **Windows 10/11 / x64** — файл `Fluent-…-windows-x64-setup.exe`.
- **Fluent Dev для Windows** — отдельный `Fluent-Dev-…-setup.exe` с собственным каталогом данных.

Обычный Fluent проверяет обновления через 20 секунд после запуска и затем каждые 6 часов. Круглая синяя стрелка рядом с названием появляется при наличии обновления; после загрузки она сохраняет данные и обновляет приложение с перезапуском. Во время занятия перезапуск недоступен. Новая версия заменяет прежнюю.

Fluent Dev предназначен для разработки и обновляется локальной пересборкой. Данные Dev и обычного Fluent разделены.

Начиная с 0.2.1 код интерфейса в распространяемых сборках обфусцирован, карты исходников и отладочные символы исключены. Это усложняет анализ кода, но не запрещает копирование приложения и ресурсов. Предыдущие версии не получают эту защиту задним числом.

Для функций AI нужен установленный Codex CLI и вход в ChatGPT. Исходный код Fluent хранится в закрытом репозитории. Здесь публикуются только установщики и файлы обновлений.

Обновления проверяются криптографической подписью. Apple notarization и Windows Authenticode пока не настроены: при первой установке система может сообщить о неизвестном издателе.
